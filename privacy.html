考研秘書 隱私權政策 / Privacy Policy

最後更新：2026-10-30

誰在使用

考研秘書只給作者本人使用，只會存取作者自己授權的那一個 Gmail 帳號。不提供給其他人，也不收集任何其他人的資料。

存取哪些 Google 資料、拿來做什麼

  • 讀取信件（寄件者、主旨、內文）：分類信件、寫每日摘要、找出收件人的 email 地址。
  • 修改標籤：貼上分類標籤、把不重要的信移出收件匣。不會刪除信件。
  • 草稿與寄信：只在作者於 Discord 確認並選好時間後，寄出作者要求寫的信。
  • 篩選器設定：作者選擇封存某個寄件者時，建立 Gmail 篩選器。

資料存在哪裡、跟誰分享

  • 程式在作者自己的 Mac 上執行。OAuth 授權 token 存在 macOS 鑰匙圈；分類結果和摘要存在本機檔案。
  • 為了分類與寫草稿，信件的寄件者、主旨與內文節錄會傳給 Anthropic 的 Claude（透過作者自己的 Claude 帳號）處理。
  • 摘要與草稿會傳到作者自己的私人 Discord 頻道。
  • 不會出售、出租或分享給任何其他第三方，也不會用於廣告。

Google API 使用聲明

考研秘書使用與傳輸從 Google API 取得的資訊時，遵守 Google API Services User Data Policy，包含其中的 Limited Use 規定。

撤銷與刪除

隨時可以到 Google 帳戶的第三方存取權移除考研秘書。刪除本機的程式資料夾與鑰匙圈項目，就會刪掉所有本機資料。

English summary. Kaoyan Secretary is used only by its author and accesses only the author's own Gmail account. It reads messages to classify and summarize them, changes labels to organize the inbox (it never deletes mail), creates Gmail filters the author chooses, and sends emails only after the author explicitly approves them. It runs locally on the author's Mac; OAuth tokens are stored in the macOS Keychain. Message excerpts are processed by Anthropic's Claude under the author's own account, and summaries are posted to the author's private Discord channel. No data is sold, shared with other third parties, or used for advertising. Use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements. Access can be revoked at any time at myaccount.google.com/permissions.
